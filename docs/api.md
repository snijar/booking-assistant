# Краткая карта API

Все URL относительно `http://127.0.0.1:8000`. Сессия гостевая, сервер выдаёт HttpOnly-cookie через `POST /api/session`; её нужно сохранять в cookie jar клиента. Для POST нужен заголовок `X-Requested-With: booking-assistant`.

| Метод и маршрут | Действие | Доступ |
|---|---|---|
| `GET /api/health` | Готовность SQLite | Публичный |
| `GET /api/config` | Текущий день МСК, горизонт | Публичный |
| `GET /api/services` | Услуги и условные цены | Публичный |
| `GET /api/slots?day=2026-10-16` | Слоты и занятость без данных клиента | Публичный |
| `POST /api/session` | Получить / сохранить гостевую сессию | Публичный |
| `GET /api/bookings` | Свои записи | Cookie / Bearer |
| `GET /api/bookings/{id}` | Своя запись | Cookie / Bearer |
| `POST /api/bookings` | Создать | Cookie + ключ повтора |
| `POST /api/bookings/{id}/cancel` | Отменить | Cookie + ключ повтора |
| `POST /api/bookings/{id}/reschedule` | Перенести | Cookie + ключ повтора |
| `POST /api/admin/login` | Вход по локальному ключу | Случайный admin key |
| `POST /api/admin/logout` | Выход и отзыв admin-cookie | Cookie |
| `GET /api/admin/bookings?day=2026-10-16` | Последние 500 записей, необязательный фильтр | Только admin |

Пример тела создания (дату замените на завтрашнюю в пределах горизонта):

```json
{"service_id": "consultation", "starts_at": "2026-10-16T10:00:00+03:00"}
```

Заголовок `Idempotency-Key: example-create-001` должен быть уникальным для нового действия. Допустимы латиница, цифры, `:`, `_`, `-`, длина 8–128. Повтор идентичного запроса с тем же ключом возвращает исходный результат и `Idempotency-Replayed: true`. При создании первый ответ — 201, повтор — 200.

Тело переноса: `{"starts_at": "2026-10-16T11:00:00+03:00"}`. Отмена не требует тела. `telegram_id`, `user_id` и клиентская цена запрещены в теле создания. Нельзя задать собственную длительность.

Ошибки: 401 — нет сессии; 403 — не администратор / CSRF; 404 — запись отсутствует или принадлежит другому; 409 — занятый слот, конфликт ключа, недопустимый переход; 422 — неверный ввод; 503 — база временно недоступна.

```json
{"error": {"code": "slot_taken", "message": "Это время уже занято. Выберите другое."}}
```

Текущее состояние после повтора берите через GET: сохранённый идемпотентный ответ отражает момент исходной операции. Публичной выдачи токенов других пользователей, приёма Telegram update и массовой рассылки в API нет.
