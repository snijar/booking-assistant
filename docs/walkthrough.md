# Проверка за несколько минут

1. Выполните команды запуска из README, откройте `http://127.0.0.1:8000`. На экране явно указаны демо-режим и время Москвы.
2. Оставьте «Консультация», выберите завтрашнюю дату и 10:00, нажмите «Подтвердить запись». Справа появится подтверждение; слот станет недоступным.
3. Откройте приложение в другом профиле / приватном окне. Слот 10:00 занят, а список «Мои записи» пуст. Чужие записи не раскрываются.
4. В первом окне нажмите «Перенести», выберите свободное 11:00, сохраните. Номер записи сохранится, 10:00 освободится.
5. Нажмите «Отменить», затем «Да, отменить». Статус станет «Отменена», время снова доступно.
6. Откройте `/admin`, введите случайный ключ из локального терминала. Проверьте список и фильтр по дате, затем выйдите.
7. Остановите сервер через Ctrl+C и запустите той же командой. Записи останутся в базе, веб-сессия продолжит работать. Ключ администратора при новом запуске будет новым; ранее выданные ключи живут до своего срока.
8. Запустите `uv run pytest`. Конкурентный тест отправляет восемь операций к одному файлу SQLite: создаётся одна активная запись. Тест неудачного переноса подтверждает сохранение старого времени.
9. `uv run python -m booking telegram-simulate` показывает локальную работу команд без Telegram-токена. Это не доказательство реальной доставки сообщений.

Для отдельной автоматической браузерной проверки: `uv run playwright install chromium`, затем `uv run python scripts/browser_check.py`. Скрипт использует свою временную БД и не меняет ваши демо-записи.
